## 📌 About

**SkillMatch** is a full-stack AI-powered web platform that automatically matches employees to job openings within an organization — replacing slow, biased, manual HR processes with intelligent, explainable, and instant recommendations.

Built as a **Final Year Engineering Project at ESPRIT**, in direct partnership with **Magharebia Assurance**.

## 🧰 Tech Stack

### Frontend
| Tool | Purpose |
|---|---|
| **React.js** | UI framework — component-based interface |
| **v0 by Vercel** | AI-assisted UI design and prototyping |
| **Netlify** | Frontend deployment and hosting |

### Backend
| Tool | Purpose |
|---|---|
| **NestJS** | REST API — business logic and routing |
| **MongoDB** | NoSQL database — profiles, jobs, matches |
| **Docker** | Containerization — consistent environments |
| **Render** | Backend deployment and hosting |

### AI Engine
| Tool | Purpose |
|---|---|
| **Python** | Core AI and NLP processing |
| **NLP Libraries** | Skill extraction and semantic understanding |
| **Matching Algorithm** | Candidate scoring and ranking engine |

## ✨ Key Features

- 🧠 **AI Recommendation Engine** — semantic skill matching beyond keywords
- 📊 **Explainable Match Scores** — every result is justified and transparent
- 👤 **Employee Profile Management** — skills, experience, CV upload
- 💼 **Job Posting & Management** — full HR job lifecycle
- 📋 **HR Dashboard** — filter, compare, and export candidates
- 🔐 **Role-based Access** — HR Manager · Employee · Admin
- 🔔 **Smart Notifications** — real-time match alerts
- ♿ **Accessibility Widget** — Screen Reader, Dyslexic Font, High Contrast & more
- 🌍 **Multilingual** — French and English
