## 📌 About the Project

**SkillMatch** is a smart web platform built to solve one of the most overlooked challenges in HR — finding the right employee for the right job, from within the organization.

Developed as a **Final Year Engineering Project at ESPRIT**, in direct partnership with **Magharebia Assurance**, SkillMatch uses Artificial Intelligence and Natural Language Processing to automatically analyze employee profiles, understand their skills, and instantly surface the best-fit candidates for any open position.

No more manual screening. No more overlooked talent. No more bias.

---

## 🚀 Key Features

| Feature | Description |
|---|---|
| 🧠 **AI Recommendation Engine** | Matches employees to jobs based on deep skill understanding |
| 📊 **Match Scoring** | Every candidate gets a score with a clear explanation |
| 👤 **Employee Profiles** | Skills, experience, certifications, CV upload |
| 💼 **Job Management** | Post, edit, and manage job openings |
| 📋 **HR Dashboard** | View, filter, and compare candidates in one place |
| ♿ **Accessibility Widget** | Screen Reader, Dyslexic Font, High Contrast, Text Magnification & more |
| 🔔 **Smart Notifications** | HR and employees notified on new matches |
| 🔐 **Role-based Access** | HR Manager · Employee · Admin |
| 🌍 **Multilingual** | French and Arabic supported |

---

## ♿ Accessibility

SkillMatch includes a **built-in accessibility widget** with:

- 👁️ High Contrast & Monochrome modes
- 🔤 Dyslexic Font & Text Magnification
- 📖 Reading Guide & Spotlight
- 🖱️ Large Cursor & Focus Rings
- 🔇 Reduce Motion
- 🔊 Screen Reader (text-to-speech)

> *Accessibility is not a feature in SkillMatch — it is a foundation.*
